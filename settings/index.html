How to get developer access?

Easiest way is to goto this settingpage through http://developer.athom.com/tools/app-settings).
Goto http://developer.athom.com/api/projects to get your client secret and secret it.
Then click on Save Client.
Then copy the URL from the goto-url into your browser and follow the steps.
When the browser returns, copy the code into the Code from Athom field en click save changes (dont wait to long).
